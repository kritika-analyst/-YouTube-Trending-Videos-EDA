#  Exploratory Data Analysis (EDA) on YouTube Trending Videos Dataset

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the YouTube Trending Videos Dataset for India. The goal is to uncover patterns, trends, and insights from trending YouTube videos using Python data analysis and visualization libraries.

##  Objectives

* Analyze the most popular YouTube video categories.
* Study the distribution of video views.
* Examine the relationship between views and likes.
* Identify the most active trending channels.
* Explore correlations between engagement metrics.
* Analyze video publishing time patterns.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset

Dataset: YouTube Trending Videos Dataset (India)

File Used:

* INvideos.csv

##  Visualizations Included

### 1. Top 10 Trending YouTube Categories

Bar chart showing the most frequently trending video categories.

### 2. Views Distribution

Histogram illustrating how views are distributed across trending videos.

### 3. Likes vs Views Analysis

Scatter plot showing the relationship between video views and likes.

### 4. Correlation Heatmap

Heatmap displaying correlations among:

* Views
* Likes
* Dislikes
* Comment Count

### 5. Most Active Channels

Bar chart identifying channels that appear most frequently in trending videos.

### 6. Publishing Time Analysis

Visualization of video publishing patterns across different hours of the day.

## 🔍 Key Insights

* Entertainment and Music categories dominate YouTube trending videos.
* Videos with higher views generally receive more likes.
* Likes, views, and comments show strong positive correlations.
* Certain channels consistently appear in trending lists.
* Video publishing activity varies across different hours of the day.
